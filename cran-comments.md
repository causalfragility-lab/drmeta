
## Submission

This is an update to the previously published CRAN package drmeta 0.1.0.

Version 0.2.0 substantially revises the package to implement the
design-indexed location-scale specification described in the accompanying
methodological work. The update adds constrained and unrestricted scale
models, location moderators, observed-support variance-ratio and
scale-attenuation summaries, boundary-aware bootstrap inference,
influence diagnostics, and revised documentation and tests.

The earlier design-explained heterogeneity decomposition has been removed.
